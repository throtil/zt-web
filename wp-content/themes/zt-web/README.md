# Тема сайта

Каталог смонтирован в контейнер WordPress из рабочей копии (только для чтения),
поэтому правка файла темы видна в браузере сразу, без пересборки образа.

Самой темы пока нет: вёрстка, шаблон обзора и блоки — отдельная итерация
после инфраструктуры. Пока каталог пуст, WordPress его не видит как тему
и использует стандартную.

Когда тема появится, её файлы (`style.css`, шаблоны, `functions.php`,
паттерны разметки) лежат здесь и версионируются. Правило остаётся: код
попадает на сервер только через репозиторий — встроенный редактор файлов
в админке отключён для всех, включая администратора.
