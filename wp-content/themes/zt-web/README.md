# Тема сайта

Дочерняя тема Twenty Twenty-Five. Каталог смонтирован в контейнер WordPress из
рабочей копии (только для чтения), поэтому правка файла видна в браузере
сразу, без пересборки.

## Что здесь лежит и что не лежит

| Есть | Нет и не будет |
|---|---|
| `templates/` — главная, список рубрики, статья, страница | палитры и шрифты |
| `parts/` — шапка с блоком меню, подвал | состав меню: он в базе |
| `patterns/` — заготовки разметки обзоров | тексты статей |
| `style.css` — правила сетки фотографий и блоков заготовок | |
| `theme.json` — ширина текста, полноэкранный просмотр | |

Цветов и шрифтов в теме нет **сознательно**: их хозяин — база, их меняет
редактор через админку, и запись в файле создала бы второго хозяина у слоя,
где он не нужен. Подробности и обоснование — `docs/theme-layers.md`.

## Правило: шаблоны меняются только коммитом

Не править шаблоны через админку — **и разработчику тоже**. Запись шаблона в
базе заменяет одноимённый файл целиком, и правка файла после этого не видна:
деплой проходит, журнал чист, страница не меняется.

Проверить, не перебит ли шаблон: `./scripts/wp-templates.sh`.

## Мелочи, которые неочевидны

**`style.css` подключается из `functions.php`.** У блочных тем WordPress его
сам не подключает — родительская Twenty Twenty-Five обходится одним
`theme.json` и своего `style.css` на страницах не отдаёт.

**В шапке стоит блок меню без пунктов и без ссылки на запись меню.** Сами
пункты — запись в базе, её хозяин редактор; заводит её `zt-structure.php` при
первом подъёме по дереву рубрик, он же подставляет ссылку при отрисовке, по
слогу записи. Записать ссылку в файл нельзя: её значение — идентификатор,
который выдаёт база.

**Пункты меню записаны адресами, а не идентификаторами рубрик.** По той же
причине. Отметку текущего раздела, которую ядро при этом делать перестаёт,
возвращает фильтр в `functions.php`.

**У галереи тройки обязателен `linkTo: none`.** Полноэкранный просмотр ядро
даёт только изображению без ссылки; кадр со ссылкой уводит на страницу
вложения, и сетка перестаёт показывать что-либо вообще.

**Зазор сетки задан через `--wp--style--gallery-gap-default`.** Ядро берёт из
этой переменной запасное значение и из него же считает ширину кадра. Зазор,
заданный иначе, разошёлся бы с расчётом ширины.

## Тема зависит от mu-plugin

`zt-structure.php` заводит рубрики, само меню и общую заготовку с врезкой, на
которую ссылается каркас обзора. Без него заготовка обзора вставит врезку
текстом, а в шапке окажется не наше меню: не найдя записи, ядро возьмёт
последнее опубликованное меню, а не найдя ни одного — соберёт своё из списка
страниц.
