# Декларативный список плагинов WordPress.
#
# Формат: одна строка на плагин, `slug==версия`. Версия обязательна:
# «последняя» — не воспроизводимое значение, при пересоздании сервера оно
# даст другой набор кода.
#
#   wordpress-seo==24.1
#
# Пустые строки и строки, начинающиеся с #, игнорируются.
#
# Список — источник истины. Установка плагина через админку в обход этого
# файла считается временной: при пересоздании сервера такой плагин не появится.
# Расхождение показывает `scripts/plugins-sync.sh check`, приведение набора
# в соответствие — `scripts/plugins-sync.sh apply`, и оно же выполняется
# шагом деплоя.
#
# Набор целиком принадлежит разработчику: у редактора прав на установку нет.
#
# Сейчас список пуст сознательно: инфраструктурной итерации плагины не нужны,
# а выбор плагинов для медиа-пайплайна и вёрстки — решение тех итераций.
